# Archived Stack v1 scripts

These files preserve the historical Stack v1 workflow referenced by `docs/archive/stack/`.
They are not current entry points and are excluded from the standard lint command.

Several launchers reference the removed legacy `scripts/run_rollouts.py` or paths relative to the
old `scripts/` directory. Use the repository history and the matching local experiment
`source.patch` before attempting to reproduce a historical Stack run. Current development should
use the PickPlace scripts directly under `scripts/`.
