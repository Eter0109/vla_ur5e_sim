# UR5e SmolVLA 机械臂抬升任务实验报告 (2026-07-17)

本项目旨在优化 NVIDIA Isaac Lab / Robosuite 仿真环境中的 UR5e/Robotiq 机械臂方块抬升任务。针对原基线模型（3k 步）在 Held-out 测试集上成功率仅 50.0%（未达 60.0% 验收红线）且存在“抓取落空及抬升后脱落”的痛点，本实验通过优化训练效率、梯度的维度加权以及微调推理段的时序策略，成功实现了全面达标。

---

## 1. 实验配置与超参数说明

### 1.1 训练超参数优化
优化后的微调训练配置相比原基线配置进行了关键调整：

| 超参数 | 基线配置 (Baseline) | 优化配置 (Ours) | 调整目的 |
|---|---|---|---|
| **Batch Size** | 4 | **8** | 稳定梯度估计，防止小 batch 带来的剧烈震荡 |
| **训练步数 (Steps)** | 3,000 | **10,000** | 增加迭代步数，确保模型在 500 demos 全量数据集上充分收敛 |
| **学习率 (LR)** | 1e-4 | **2e-5** | 降低微调学习率，配合 Warmup 保证平稳收敛并防止过拟合 |
| **旋转损失权重** | 1.0 | **0.01** | **关键修复**：由于方块抬升任务中物体具有对称性，旋转回归通道存在较大的噪声。将其权重降低 100 倍以避免无效梯度占据主导，使得模型聚焦于平移与抓取通道的回归。 |
| **抓手损失权重** | 1.0 | **2.0** | 强化抓手开合动作的梯度信号，提升二分类边界的确信度 |

### 1.2 推理时序控制与滤波配置
在仿真闭环评估阶段，采用以下时序策略与控制器配合：
- **时序融合方式 (Temporal Ensemble)**: 开启。指数衰减因子 `temporal_ensemble_decay = 0.5`，动作重规划步长 `replan_steps = 4`。
- **抓手决策机制 (Gripper Mode)**: `confirm` 确信过滤机制（需连续 2 个步长预测关闭才真正执行关爪动作，即 `gripper_confirm_steps = 2`），防止单步噪声引发的抓爪抖动与提早闭合。
- **评测清单与范围**:
  - Validation 集: [validation.json](file:///D:/vla_ur5e_sim/data/manifests/validation.json) (30 episodes)
  - Test (Held-out) 集: [test.json](file:///D:/vla_ur5e_sim/data/manifests/test.json) (50 episodes)

## 3. 典型失败模式与根因分析

尽管测试集成功率提升至 **70%**，仍有 15 局（共 50 局）未能成功完成任务。解析 `eval_efficiency_test50.json` 的单局诊断字段，我们总结出以下两类主要失败模式：

### 3.1 早期闭合与接近失败 (Early Closure / Approach Failure)
- **典型局数**: `test-0000` (抓手首次闭合距离方块达 4.6cm，导致抓空)、`test-0009`、`test-0011`、`test-0023` 等。
- **表现形式**: 机械臂在尚未对准或接触到方块时即预测出闭合动作（`first_gripper_close_step` 提前激活，且接近未成功 `approach_success = false`）。
- **根因**: 虽然我们通过 `confirm` 策略延迟了抓爪，但 VLA 在某些视觉初始偏差较大（如偏角极限）的场景下，深度知觉或多模态特征对“即将接触方块”这一临界状态的理解存在泛化死角。

### 3.2 抬升阶段滑落/持握不稳 (Slippage / Hold Failure)
- **典型局数**: `test-0001` (最大抬升高度达 10.0cm，但仅维持了 4 个步长)、`test-0019` (仅维持了 3 个步长)。
- **表现形式**: 机械臂成功接近并完成了抓爪（`approach_success = true`，`grasp_attempted = true`），也将物体拔地而起，但在空中维持持握少于 10 个步长便滑落。
- **根因**: Robosuite 物理引擎中的接触力学模型对抓手的摩擦力和夹紧力敏感度较高。当夹紧点并非方块几何中心时，偏心力矩容易导致方块在重力与手臂微小抖动的作用下发生物理滑落。

## 4. 结论与下一步工作建议

### 实验结论
通过修复旋转通道对梯度的干扰（`RotationLossWeight=0.01`），增加 batch size 和迭代步数（`BatchSize=8`，`10k` 步），模型不仅解决了原本不收敛的问题，还极大增强了抓手关闭的确信度。该实验证明，**多模态大动作模型微调中，通道权重的细致标定与充分的训练时长对闭环仿真表现至关重要。**

### 下一步建议
1. **抓取力矩主动控制**: 在夹持器动作输出中引入阻抗或抓取力回馈，在物理引擎层面给物体施加更稳定的法向力。
2. **多视角相机融合**: 当前方案易受单视角的深度遮挡影响，引入 Wrist 相机或侧向相机数据流有助于进一步减少早期闭爪和接近落空的情形。
